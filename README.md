# Devkit

Devkit is a shared development foundation for TypeScript, Rust, and mixed projects. It brings reusable tooling, container environments, and project templates into one repository.

Applications live in their own repositories, with a root Makefile and native manifests under `apps/<name>`.

The first supported development platform is Linux with Docker Compose. The implementation is being built and validated before its first release.
